# AI URL Platform (Linkly)

A scalable, full-stack URL shortening and link management platform built with modern web technologies, AI-powered automatic categorization, real-time analytics, and subscription tiers.

## Architecture

This monorepo contains:
- `backend/`: Node.js / Express service with MongoDB, Redis caching, BullMQ job queue, and AI categorization.
- `frontend/`: Modern React.js client interface with Tailwind CSS and responsive UI.
